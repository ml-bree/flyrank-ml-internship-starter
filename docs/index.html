User Intent Prediction for Search Ranking

Author: Breattah Okeyo · Date: August 2026

Machine Learning Internship User Intent Lane

Abstract

This paper presents a machine learning approach to predicting user intent from search engagement signals. Using the FlyRank ML Internship dataset, I built a Random Forest classifier that predicts whether a page matches user intent based on CTR, engagement_rate, and position metrics. The model achieves 0.760 Precision@50, outperforming both the hand-rule baseline (0.680) and a single decision tree (0.740).

1. Introduction

Search ranking systems need to understand what users actually want. A page that ranks high but doesn't match user intent leads to poor engagement and user frustration. The challenge is that user intent isn't directly observable — we can only see engagement signals.

This work addresses the question: Can we predict whether a page matches user intent using search engagement signals?

2. Data

Dataset: FlyRank ML Internship warehouse release (Hugging Face)

  • fact_content_daily_performance_sample — daily search performance metrics
  • dim_content — content metadata

Time window: June 2026

Exclusions: Pages with less than 10 impressions were excluded.

3. Methodology

3.1 Task Type

Binary Classification — predict whether a page matches user intent (1) or not (0).

3.2 Features

FeatureDescription
avg_positionAverage search position
ctrClick-through rate
engagement_rateGA4 engaged sessions
impressions_90d90-day impressions

3.3 Label Definition (Proxy)

high_intent = 1 if ctr > 0.05 AND engagement_rate > 0.3

3.4 Baseline

Hand-rule: if ctr < 0.02 AND avg_position > 10 → flag for refresh

Baseline Precision@50 = 0.680

3.5 Validation Design

  • Split: 80/20 random split
  • Stratification: Balanced by target
  • No future data leakage — features and label from same time window

3.6 Models

  1. Decision Tree (max_depth=5) — interpretable baseline
  2. Random Forest (n_estimators=100, max_depth=5) — ensemble improvement

4. Results

Model vs Baseline Comparison

Feature Importance

  1. CTR — most important
  2. engagement_rate — second
  3. avg_position — third
  4. impressions_90d — least important

Error Analysis

  • False positives: Pages flagged as high intent but not. Happens when engagement_rate is high but CTR is low.
  • False negatives: Pages missed. Happens when CTR is high but engagement_rate is low.

5. Limitations

  • Proxy target: Engagement is a proxy for intent, not a direct measure.
  • Sample bias: June 2026 only — may not generalize to other months.
  • Feature limitations: Only four features used.
  • No client-holdout: Random split, not by client.

This is an observed, directional analysis, not a causal claim.
