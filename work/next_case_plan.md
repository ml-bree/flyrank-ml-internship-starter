# How to Add the Next Case Study

## The Three-Beats Shape (From Week 2)

Every case study follows the same simple structure:

1. **Problem:** What was the situation? What needed fixing?
2. **What I did:** What did you build? What decisions did you make?
3. **Outcome:** What happened? Numbers, impact, learnings.

## Steps to Add a New Case

### Step 1: Open Claude Project
- Open my Claude Project: **"Job Application Workflow"**
- My voice card, identity kit, and past case studies are already there

### Step 2: Write the Case (3 Beats)
- Use the same structure as my FlyRank ML Pipeline case
- Start with the problem, then what I did, then the outcome
- Use my voice card: "Build things, deliver results, have fun, be direct"
- Keep it under 200 words
- Include at least one number

### Step 3: Review and Refine
- Read it out loud — does it sound like me?
- Cut anything I wouldn't say
- Check: does it prove something new?

### Step 4: Add to Portfolio
- Open my `index.html` file
- Add the new case to the Work section
- Deploy to Netlify (drag and drop)

### Step 5: Share
- Update my LinkedIn with the new case
- Add to my CV if relevant

## Why This Works

The Claude Project already knows:
- My voice (voice card)
- My colors and fonts (identity kit)
- My existing cases (case_studies.md)

So adding a new case is a short conversation, not a rebuild. The hard part (setting up the stack and voice) is already done.
